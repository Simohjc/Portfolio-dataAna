Featured Project — My First End-to-End Python Web App

UBOX Solutions — Load Profit Analyzer

A Python and Streamlit web app I built for UBOX Solutions, a Houston-based cargo van delivery and last-mile logistics company, to evaluate whether a load is actually worth accepting. It takes load pay, mileage, fuel price, driver pay, tolls, and maintenance cost as input, then instantly calculates net profit, profit per mile, operating margin, and deadhead efficiency — turning a decision that used to be napkin math into a clear, data-backed call. This was my first project taken all the way from raw calculation logic to a live, publicly deployed application.

Python Streamlit Pandas Session State Data Validation CSS Styling CSV Export Cloud Deployment

What I Built

  • Load profitability engine calculating net profit, profit per mile, operating margin, and deadhead percentage from real trucking cost inputs
  • Automatic load rating (Great / Acceptable / Low Profit / Poor) and deadhead efficiency rating based on the calculated results
  • Session-based load history using Streamlit's session state, with input validation and duplicate-submission protection
  • Color-coded, horizontally scrollable history table with one-click CSV export for record-keeping
  • Custom-branded UI — logo, color theme, and styled metric cards — built entirely with scoped CSS
  • Deployed live on Streamlit Community Cloud so the tool is actually usable by the business, not just running locally
