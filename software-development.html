Featured Project — Full-Stack Python App with Cloud Database

UBOX Solutions — Load Profit Analyzer

A Python and Streamlit web app I built for UBOX Solutions, a Houston-based cargo van delivery and last-mile logistics company, to evaluate whether a load is actually worth accepting. It takes load pay, mileage, fuel price, driver pay, tolls, and maintenance cost as input, then instantly calculates net profit, profit per mile, operating margin, and deadhead efficiency — turning a decision that used to be napkin math into a clear, data-backed call. What started as a simple calculator grew into a full-stack application: every submitted load is now permanently saved to a cloud PostgreSQL database (Neon), with secure credential management and a proper Git version-control workflow.

Python Streamlit Pandas PostgreSQL Neon psycopg2 Object-Oriented Programming Git & GitHub Streamlit Secrets Data Validation CSS Styling Cloud Deployment

What I Built

  • Load profitability engine calculating net profit, profit per mile, operating margin, and deadhead percentage from real trucking cost inputs
  • Automatic load rating (Great / Acceptable / Low Profit / Poor) and deadhead efficiency rating based on the calculated results
  • An object-oriented Load class modeling every submitted load, feeding a parameterized SQL insert to prevent SQL injection
  • Persistent cloud database storage on Neon (serverless PostgreSQL), so load history survives restarts and redeployments — not just the browser session
  • Secure credential handling via Streamlit secrets, both locally and in production, so no database password is ever exposed in the public repo
  • Color-coded, horizontally scrollable history table with one-click CSV export for record-keeping
  • Custom-branded UI — logo, color theme, and styled metric cards — built entirely with scoped CSS
  • Deployed live on Streamlit Community Cloud, with a full Git/GitHub workflow for version control

Project Evolution

  • Started as a Streamlit form with the core profitability calculations
  • Added branding, styled metric cards, and a color-coded, scrollable history table
  • Introduced session-based history with duplicate-entry prevention, validation, and CSV export
  • Deployed live on Streamlit Community Cloud
  • Refactored the data model around an object-oriented Load class
  • Connected the app to PostgreSQL with psycopg2 for permanent data persistence
  • Migrated the database to Neon (cloud PostgreSQL) so the live deployed app could reach it
  • Replaced hardcoded credentials with Streamlit secrets for secure, production-safe configuration
  • Set up Git and GitHub version control from the command line to manage ongoing changes
