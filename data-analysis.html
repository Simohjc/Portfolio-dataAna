A complete SQL data cleaning portfolio project using PostgreSQL to transform raw Google Trends data into a clean, analysis-ready dataset. This project challenged me to work through the entire data preparation process — combining multiple datasets, identifying data quality issues, standardizing inconsistent values, converting messy text dates into timestamps, validating duplicates, handling missing values, and documenting every cleaning step in a professional workflow.

PostgreSQL SQL Data Cleaning UNION ALL Views ROW_NUMBER() TO_TIMESTAMP() REGEXP_REPLACE() TRIM() REPLACE()

What I Explored

  • Combined 19 Google Trends datasets into one SQL view using UNION ALL
  • Standardized inconsistent text values using TRIM() and REPLACE()

  • Created new timestamp columns for accurate time-based analysis
  • Cleaned search volume values (e.g., 2K+ → 2000)
  • Validated duplicate records using ROW_NUMBER() and PARTITION BY

Featured Project — End-to-End Global Sales Analysis & Power BI Dashboard

Global Sales Performance Analysis | 2025–2026

An end-to-end sales analytics project analyzing 1,838 transactions across eight countries. I used PostgreSQL to audit, clean, standardize, validate, and analyze the raw sales data before converting international sales into a common USD reporting currency. I then used Power BI and DAX to build an interactive executive dashboard covering revenue, profitability, product performance, market performance, sales channels, and monthly growth trends. The project concludes with executive insights and business recommendations designed to turn the analysis into actionable decisions.

PostgreSQL SQL Power BI DAX Data Cleaning Data Validation CTEs Window Functions LAG() DENSE_RANK() Currency Conversion KPI Analysis Business Intelligence

Project Workflow

  • Audited raw sales data from 8 countries covering the 2025–2026 reporting period
  • Cleaned inconsistent text, currency, discount, numeric, and date fields using PostgreSQL
  • Standardized fields using TRIM(), LOWER(), UPPER(), REPLACE() and PostgreSQL data-type conversions
  • Checked for missing values and duplicate transactions before beginning the analysis
  • Standardized international sales into USD using a reporting exchange-rate table
  • Calculated executive KPIs including revenue, profit, units sold, transactions, AOV, profit margin, and average discount
  • Compared country performance using revenue contribution, profitability, average order value, and ranking analysis
  • Used DENSE_RANK() to compare markets by revenue, profit, and profit margin
  • Used LAG() and CTEs to calculate month-over-month revenue and profit growth
  • Built an interactive Power BI executive dashboard with country, product-category, and date filtering
  • Converted the analytical findings into executive insights and management recommendations

Key Business Results

  • $2.87M in total net revenue
  • $874K in total profit
  • 30.45% overall profit margin
  • 15.24K units sold across approximately 2K transactions
  • Average order value of approximately $1.56K
  • Technology generated approximately $1.63M, making it the largest product category
  • Laptops generated approximately $1.08M, making them the strongest individual product
  • Australia generated approximately $450K in net revenue, leading the eight analyzed markets
  • The United Kingdom achieved the highest profit margin at 32.45%
  • Retail was the strongest sales channel at approximately $750K in net revenue
  • June 2026 revenue declined 2.84% from May, highlighting weaker recent revenue momentum
