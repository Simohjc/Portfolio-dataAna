## 🚀 Featured Projects

### Software Development

#### [UBOX Solutions — Load Profit Analyzer](https://simohjc.github.io/Portfolio-dataAna/software-development.html)
A full-stack Python and Streamlit web application built for a real Houston-based logistics company to evaluate load profitability — calculating net profit, profit per mile, deadhead percentage, and operating margin from real-world cost inputs.

What started as a calculator grew into a complete application: an object-oriented `Load` class, a PostgreSQL database migrated to [Neon](https://neon.tech) for permanent cloud persistence, secure credential management via Streamlit secrets, and a full Git/GitHub version-control workflow — deployed live on Streamlit Community Cloud.

**Stack:** Python · Streamlit · Pandas · PostgreSQL · Neon · psycopg2 · Git

🌐 [Live App](https://ubox-solutions-load-profit-analyzer-mfdxvubiu267xohphbg4ma.streamlit.app/) · 💻 [GitHub Repository](https://github.com/Simohjc/UBOX-Solutions-Load-Profit-Analyzer)

### Data Analysis

#### [Global Sales Performance Analysis](https://simohjc.github.io/Portfolio-dataAna/data-analysis.html)
An end-to-end sales analytics project covering 1,838 transactions across 8 countries. Used PostgreSQL to audit, clean, standardize, and validate raw sales data, converted international sales into a common USD reporting currency, then built an interactive Power BI executive dashboard covering revenue, profitability, product performance, and monthly growth trends.

**Stack:** PostgreSQL · SQL · Power BI · DAX · CTEs · Window Functions

🌐 [Live Project](https://simohjc.github.io/global-sales-performance-analysis/) · 💻 [GitHub Repository](https://github.com/Simohjc/global-sales-performance-analysis)

#### [Walmart Sales Data Analysis](https://simohjc.github.io/Portfolio-dataAna/data-analysis.html)
An end-to-end SQL portfolio project analyzing Walmart sales data with PostgreSQL — yearly and weekly rankings, peak sales months, holiday vs. non-holiday trends, and week-over-week volatility.

**Stack:** PostgreSQL · SQL · Window Functions · DENSE_RANK() · LAG()

🌐 [Live Project](https://simohjc.github.io/walmart_data_analysis_project/) · 💻 [GitHub Repository](https://github.com/Simohjc/walmart_data_analysis_project)

#### [Google Trends Data Cleaning with PostgreSQL](https://simohjc.github.io/Portfolio-dataAna/data-analysis.html)
A complete SQL data cleaning project — combining 19 raw Google Trends datasets into a single analysis-ready dataset, standardizing inconsistent values, converting messy date strings into timestamps, and validating duplicates.

**Stack:** PostgreSQL · SQL · UNION ALL · ROW_NUMBER() · REGEXP_REPLACE()

🌐 [Live Project](https://simohjc.github.io/Google-Trends-Data-Cleaning-with-PostgreSQL/) · 💻 [GitHub Repository](https://github.com/Simohjc/Google-Trends-Data-Cleaning-with-PostgreSQL)
